CineScope — интерактивный каталог фильмов с премиальным
кинематографичным дизайном. Самостоятельный frontend-проект
для портфолио: чистый HTML, CSS и Vanilla JavaScript
без сборщиков, фреймворков и backend.


------------------------------------------------------------
О ПРОЕКТЕ
------------------------------------------------------------

CineScope — это не «учебная страница с карточками», а
законченный интерфейсный продукт: с выразительным hero-блоком,
живым каталогом, работающими фильтрами, модальным окном с
подробной информацией и системой избранного, которая
сохраняется между сессиями.

Проект демонстрирует навыки:

  • семантической вёрстки и адаптивной раскладки;
  • построения визуальной системы через CSS-переменные;
  • организации Vanilla JS без зависимостей;
  • работы с пользовательским состоянием (LocalStorage);
  • внимания к доступности и деталям UI/UX.


------------------------------------------------------------
ВОЗМОЖНОСТИ
------------------------------------------------------------

КОНТЕНТ И НАВИГАЦИЯ
  • Hero-блок с рекомендуемым фильмом, рейтингом,
    жанрами и кнопками действий.
  • Каталог из 17 фильмов с обложками, жанрами, годами
    и рейтингами.
  • Блок популярных жанров — быстрый переход к категории.
  • Модальное окно с полным описанием фильма, режиссёром
    и продолжительностью.

ПОИСК И ФИЛЬТРЫ
  • Живой поиск по названию (в шапке и в каталоге —
    синхронизированы).
  • Фильтр по жанру, году выпуска и минимальному рейтингу.
  • Четыре режима сортировки: по популярности, рейтингу,
    году и названию.
  • Все фильтры работают совместно и дают корректный
    результат.
  • Кнопка сброса фильтров.
  • Переключение вида каталога: сетка и список.

ИЗБРАННОЕ
  • Добавление и удаление фильмов в один клик.
  • Счётчик избранного в шапке сайта.
  • Отдельная секция со списком сохранённых фильмов.
  • Сохранение между сессиями через localStorage.
  • Красивое пустое состояние с призывом вернуться
    в каталог.

ИНТЕРФЕЙС
  • Тёмная кинематографичная палитра с янтарным акцентом.
  • Светлая тема с сохранением выбора пользователя.
  • Плавные анимации карточек, hover-эффекты и
    микроинтеракции.
  • Недавно просмотренные фильмы в рамках сессии.
  • Toast-уведомления о действиях.

ДОСТУПНОСТЬ
  • Семантические элементы: header, main, section, footer,
    article.
  • aria-label, aria-pressed, aria-expanded, aria-live
    для интерактивных элементов.
  • Видимые focus-состояния для клавиатурной навигации.
  • Модальное окно закрывается по Escape, клику на оверлей
    и по кнопке.
  • Поддержка prefers-reduced-motion.

УСТОЙЧИВОСТЬ
  • Fallback для недоступных постеров — аккуратный тёмный
    плейсхолдер с названием.
  • Пустые состояния для поиска, избранного и результата
    фильтрации.
  • Валидация данных из localStorage — битые записи
    не ломают приложение.
  • Корректная работа при заблокированном хранилище
    (приватный режим).

ЛОКАЛЬНЫЙ ЗАПУСК

  git clone https://github.com/<ваш-логин>/cinescope.git

ПУБЛИКАЦИЯ НА GITHUB PAGES

  1. Создайте публичный репозиторий на GitHub.
  2. Загрузите три файла в корень репозитория.
  3. Откройте Settings -> Pages.
  4. Source: Deploy from a branch, Branch: main / root.
  5. Нажмите Save и подождите 30–60 секунд.
  6. Сайт будет доступен по адресу:
     https://<ваш-логин>.github.io/cinescope/

------------------------------------------------------------
АРХИТЕКТУРА JAVASCRIPT
------------------------------------------------------------

script.js построен по модульному принципу внутри одной IIFE:

  1.  Данные — массив MOVIES с 17 фильмами.
  2.  Состояние — единый объект state (фильтры, вид,
      избранное, недавние).
  3.  Утилиты — $, $$, escapeHtml, formatDuration.
  4.  LocalStorage — безопасное чтение и запись
      с обработкой ошибок.
  5.  Фильтрация и сортировка — чистые функции.
  6.  Рендеринг — renderCatalog, renderFavorites,
      renderGenres, renderSelects, renderRecent.
  7.  Модальное окно — openModal, closeModal,
      управление фокусом.
  8.  Избранное — toggleFavorite, clearFavorites.
  9.  Toast — лёгкие уведомления.
  10. События — делегирование кликов и клавиатуры
      на document.
  11. Инициализация — восстановление состояния
      и первый рендер.

КЛЮЧЕВЫЕ ПРИНЦИПЫ
  • Единственный click-обработчик через делегирование —
    не дублируется при ре-рендере.
  • Все пользовательские данные экранируются через
    escapeHtml — защита от инъекций.
  • Состояние из localStorage валидируется перед
    использованием.
  • Обработчики не навешиваются на динамические элементы
    повторно.


------------------------------------------------------------
ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ
------------------------------------------------------------

Проект использует реальные названия фильмов и правдивые
данные, где они легко проверяются (год, режиссёр,
продолжительность, жанры).

Рейтинги помечены как «Рейтинг CineScope» и представляют
собой условные демонстрационные значения — это не
официальные оценки сторонних сервисов, а внутренняя шкала
проекта.

Фильм «Город после полуночи» — полностью вымышленный,
создан специально для hero-блока как демонстрационный
контент.

Постеры загружаются с публичных CDN (TMDB Image, Unsplash)
без API-ключей. При недоступности изображения автоматически
показывается тёмный плейсхолдер с названием фильма.
